FastScreen 0.1.4: Ultra-Fast DirectX Screen Capture for Java (240–2000 FPS)

⚡ FastScreen provides hardware-accelerated, zero-copy desktop duplication and real-time screen capture for Java using DirectX 11 (DXGI 1.2+ Desktop Duplication) and native memory streaming.

In this video / demo, we showcase:
🔥 Pure Zero-Copy Desktop Capture directly to 64-byte aligned memory (0% GPU scaling overhead in FastScreen core)
🔥 Seamless FastImage 0.1.4 Pipeline Integration:
   • POINT: Ultra-fast Nearest-Neighbor resampling
   • LINEAR: AVX2 SIMD Bilinear interpolation
   • BICUBIC: High-precision Catmull-Rom cubic spline anti-aliasing
   • AREA-AVERAGE: OpenMP multi-threaded box downsampling for perfect moiré elimination
🔥 Silky-Smooth 120 FPS Synchronization via FastDWM (waitForVSync + 1ms timer period)
🔥 Win32 Window Exclusion: Prevent recursive Droste mirror loops via SetWindowDisplayAffinity (WDA_EXCLUDEFROMCAPTURE)
🔥 Virtual Desktop & Lock-Screen Resilience: Automatic silent backoff recovery on DXGI_ERROR_ACCESS_LOST / 0x80070005

🚀 Highlights in FastScreen 0.1.4:
- Clean Architectural Separation: FastScreen dedicated purely to native screen capture; all image resampling and filtering offloaded to FastImage.
- FastDWM Frame Pacing: Eliminates micro-stuttering on high-refresh (120 Hz / 144 Hz / 240 Hz) displays.
- Zero Java Heap Allocations: Triple-buffered native frame pool exposing raw FastPointer addresses.
- Auto-Recovery: Seamlessly recovers capture session when switching virtual desktops, triggering UAC, or locking Windows.

Controls in Visual Demo:
• [A] - Cycle Anti-Aliasing (Point → Bilinear → Bicubic → Area-Average)
• [E] - Toggle Window Exclusion (Exclude preview window from capture)
• [ESC] - Exit
