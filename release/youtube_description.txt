FastScreen 0.1.3: Ultra-Fast DirectX Screen Capture for Java (240–2000 FPS)

⚡ FastScreen provides hardware-accelerated, zero-copy desktop duplication and real-time screen capture for Java using DirectX 11 (DXGI 1.2+ Desktop Duplication) and native GPU render pipelines.

In this video / demo, we showcase:
🔥 Pure GPU Hardware Scaling directly inside DirectX 11 VRAM (0% CPU cost)
🔥 Real-Time Anti-Aliasing comparison:
   • GPU POINT: Fast Nearest Neighbor
   • GPU LINEAR AA: Hardware Bilinear Filtering
   • GPU BICUBIC AA: 16-Tap Catmull-Rom Cubic Spline Shader for razor-sharp detail
🔥 FastPointer & FastMemory Zero-Copy Bridge:
   • Direct 64-bit physical memory access into DirectX readback buffers
   • Seamless interop with FastImage SIMD processing without Java heap allocations (0 Bytes GC pressure)
   • Live toggle between Zero-Copy FastPointer and standard JNI array copies

🚀 Full Highlights in FastScreen 0.1.3:
- DirectX 11 HLSL Hardware Scaling: Scale 4K/1440p down to 1080p/720p on the GPU before PCIe readback, cutting bus bandwidth by up to 90%.
- 16-Tap Bicubic Catmull-Rom Spline Shader: Custom pixel shader using 4 bilinear texture taps with subpixel offsets for ultra-crisp scaling at 500–800+ FPS.
- FastPointer Zero-Copy Interop: Retrieve 64-byte aligned memory addresses (Pointer.of(addr)) directly into FastImage / FastMemory.
- Win32 Window Exclusion: Prevent Droste mirror recursion loops via SetWindowDisplayAffinity (WDA_EXCLUDEFROMCAPTURE).
- Lock-Free Triple Buffering: Decoupled capture worker and rendering loop for tearing-free, buttery-smooth previews.
- Dynamic Sub-Region Switching: Crop sub-rectangles on-the-fly without destroying DirectX device contexts.
- Win32 GDI DIBSection Fallback: Seamless automatic fallback when DXGI Desktop Duplication is unavailable.

Controls in Visual Demo:
• [A] - Cycle Anti-Aliasing (GPU Point → GPU Linear AA → GPU Bicubic AA)
• [P] - Toggle Zero-Copy Bridge (FastPointer Address vs. JNI Array Copy)
• [E] - Toggle Window Exclusion (Exclude preview window from capture)
• [L] - Cycle FPS Limits (Uncapped, 144, 60, 30 FPS)
• [SPACE] - Pause / Resume capture stream
• [ESC] - Exit
